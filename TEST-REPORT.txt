界面测试加载实际内容脚本，但模拟了 chrome.runtime / chrome.storage；后台测试使用模拟的浏览器 API。
这不是安装扩展后的完整端到端实测，没有验证真实网站、实际硬盘授权、下载、系统定时器或 Chrome 后台生命周期。
因此不能据此承诺所有网站均无兼容问题；请按 README 升级后测试实际使用场景。

升级要点
先导出旧配置，再覆盖原先加载的扩展文件夹并重新加载；不要先卸载。
新版首次使用需在设置中添加保险栓生效网站，列表为空不会拦截 Enter。
DLC 为包内按需启用模块，移除只停用功能，不删除数据。旧版配置会保留原先功能。
