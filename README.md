# Miorning Prompt Guard v1.4.6

## v1.4.6 修复 / 新增

1. 顶部 IP 图位置调整：
   - 现在图片贴紧“生成前确认”弹窗的上边缘。
   - 不再压住下面的标题和文字。

2. 顶部 IP 图新增恢复默认：
   - 左键连续点击顶部图 5 次，恢复默认图片。
   - 左键长按 1 秒，仍然可以更换图片。
   - 单击除了累计次数外不会触发其他动作。
   - 右键无动作。

3. 设置页右上角新增配置导入 / 导出：
   - 位置在关闭 X 旁边。
   - 鼠标移上去显示：仅供升级版本时使用。
   - 导出内容包含：
     - 提示词分类
     - 每个分类下的提示词
     - 快捷键设置
     - 白天 / 夜间模式
     - 成就次数
     - 已解锁成就
     - 彩蛋状态
     - 顶部图片等所有本地配置

## 安装方式

1. 解压 zip。
2. 打开 Edge。
3. 地址栏输入：edge://extensions/
4. 打开「开发人员模式」。
5. 点击「加载解压缩的扩展」。
6. 选择解压后的 `miorning-prompt-guard-v1.4.6` 文件夹。

## v1.4.8

1. 默认顶部图已换成你发的“关我屁事”黑猫读书图，并做了抠图。
2. 快捷键设置改成双列紧凑布局，减少左侧占位。
3. 提示词增加缩略图：
   - 在设置页某条提示词的输入框里，直接粘贴剪贴板里的截图 / 图片。
   - 粘贴成功后，该条提示词左侧会显示缩略图。
   - Enter 拦截弹窗中会显示“缩略图 + 提示词”。
4. 缩略图会跟随配置导入 / 导出一起保存。
